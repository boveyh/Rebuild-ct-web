零基础，从头走一遍 From scratch, in order

没写过 JavaScript 也能跟上。每章都先讲「为什么」，再落到代码。 No JavaScript needed. Each chapter explains the why before the code.

  1. 01 数据 Data 分清楚名义、序数、区间尺度 —— 后面每一次选图都靠这个判断 Nominal, ordinal, interval: every later chart choice follows from this
  2. 02 可视化流程 Workflow 把「数据 → 变换 → 映射 → 渲染」整条链路走通 Walk the whole data → transform → map → render pipeline
  3. 03 色彩 Color 颜色不只是好看：三类 colormap 用错就是误导 Colour is not decoration: the wrong colormap misleads
  4. 04 低维数据 Low-dim data 低维数据的取舍：散点、平行坐标、降维各自放弃了什么 Low-dimensional trade-offs: what scatter, parallel coords and projection each give up
  5. 05 时序数据 Time series 时间数据的三种形态：折线、日历热图、周期螺旋 Three shapes of time: line, calendar heatmap, spiral

  2. 按小节顺序过一遍讲解，遇到看不懂的看概念依赖图找到前置Work through the sections in order; use the concept map to find prerequisites

设计原则Approach
以案例为中心，不以理论为中心。每个知识点都嵌在一个具体案例里讲， 再配 ⭐ 标出的关键代码与可直接改参数的演示 —— 先看到东西动起来，再回头说它为什么这样动。 Case-first, not theory-first. Every idea is introduced inside a concrete example, followed by a ⭐ key-code block and a demo you can retune — see it move first, then explain why it moves that way.
技术栈Stack
零依赖、零构建：纯 HTML + CSS + ES Modules，D3.js v7 走 CDN。 python -m http.server 一条命令起站，不需要 npm。 禁用 JavaScript 时正文仍然完整可读。 No dependencies, no build step: plain HTML + CSS + ES Modules, with D3.js v7 from a CDN. One python -m http.server is enough; no npm. The text stays fully readable with JavaScript disabled.
数据集Datasets
新生数据、Crime 数据等已随仓库打包，浏览器直接 fetch 加载。 除 D3 之外不请求任何外部资源，断网也能跑完全部章节。 The freshman and crime datasets ship with the repository and are loaded with fetch. Apart from D3 nothing is requested externally, so every chapter works offline.
