怎么用这套材料How to use this

学生在自学

  1. 读章首的「学完这一章你应该能够」，先知道要往哪去
  2. 按小节顺序过一遍讲解，遇到看不懂的看概念依赖图找到前置
  3. 对照关键代码，注意 ⭐ 标出的写法和旁边写的坑
  4. 打开演示亲手改一改参数，看画面怎么变

教师在课堂

  1. 每章顶部有「自动导览」，可以按脚本把重点依次演一遍
  2. 讲解 / 关键代码 / 演示三个视图随时切换，不必切窗口
  3. 演示都支持实时调参，适合现场提问「如果改成这样会怎样」
  4. 按 Ctrl+K 可以直接跳到任意知识点

离线与局域网

  1. 整个站点没有任何构建步骤，克隆下来就能跑
  2. python -m http.server 8080 起一个本地服务
  3. 同一 WiFi 下的设备用本机 IP 即可访问，适合机房环境
  4. 除 D3.js 走 CDN 之外没有外部依赖

配套资源

  1. 补充 demo 集合：与章节配合的独立示例
  2. 术语表：全课程名词的集中解释
  3. 每章都有完整讲义页，适合打印
  4. 源码结构与重构说明见仓库 README 与 docs/
