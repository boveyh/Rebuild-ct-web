# 《可视化导论》课程网站 · 重构版

中国石油大学（华东）《可视化导论》课程网站的重构。

原站：<https://cinger007.github.io/vis/>
重构版线上：<https://boveyh.github.io/Rebuild-ct-web/>

**目标**：让内容展现更清晰、更适合学习。

**做法**：把「内容」和「外壳」拆开——原作者的正文、讲解、关键点一字不改；
外壳（导航、排版、检索、双语、无障碍、响应式）整体重写。
抽取与装配由 `tools/build.py` 完成，可复现、可 diff。

---

## 快速开始

```bash
# 本地预览（零依赖，只要 Python 3）
python -m http.server 8080
# 打开 http://localhost:8080
```

> **必须通过 HTTP 服务器打开，不要双击 HTML。**
> `file://` 协议下浏览器会拦截 `fetch`，站内搜索和演示数据都读不到。

GitHub Pages 可直接部署：把本目录作为站点根目录推送到 `main` 分支即可，**无需任何构建步骤**。

## 四条主线上的改动

### 1. 信息架构：补上「学习导航」这一层

原站直接给内容，学生不知道「这一章学什么、要多久、学之前得会什么」。

新增：每章的学习目标卡（共 26 条，用可检验的句式）、前置知识、
**概念依赖图**（分层有向图，自研约 6 KB 渲染器，节点可拖动）、
**三条学习路径**（零基础 / 会 JS 想快点出图 / 只补专题）、25 条术语表、
小节级阅读进度、命令面板式全站搜索（`Ctrl/⌘ + K`，126 条索引，覆盖章节正文、关键代码、演示、术语表与补充 Demo）。

> 章首与章节卡片都不再标「预计时长」。阅读速度差好几倍，写死的数字对谁都不准，
> 只会让人先打退堂鼓；要传达的是「这一章有多少东西」，用小数、演示数、代码点数就够。

### 2. 阅读体验：让内容真的更好读

- **双语**从「中英两段并排堆叠」改为「双 DOM + 一条 CSS 规则切换」——中文读者不再被迫读两遍
- **代码块**加上行号（`::before` 生成，不进复制文本）、语言标签、复制按钮，
  并用黄色左边条标出原作者用 ⭐ 标记的 **123 处**关键代码点
- **配色采用 Wong 色板**（Nature Methods 2011，色觉缺陷友好）——
  第 3 章正好讲色彩与色觉缺陷，界面自身就是那个标准的示例
- 深色模式（跟随系统 / 手动切换 / 记忆）、5 档响应式断点、窄屏表格转卡片、打印时三 tab 全展开

### 3. 修复：断链、404 与「打不开的页面」

详见 [`docs/改动说明.md`](docs/改动说明.md) 第五节。含：

- 5 章 `href="lecture"` 指向不存在的文件 → 生成真正的讲义页
- 索引里点名、仓库里从未存在的 `yearcalendar.html` → **按描述补做**（van Wijk 日历热图）
- `volumeRendering.html`（缺数据、从未接线）→ 从索引移除，不假装它存在
- `calendar*.html` 的站点根绝对路径（子路径部署必 404）→ 修正
- `regression.html` 算完回归却没画、整页空白 → 重写为真正绘制
- 第 1 章 5 个可独立运行的实验失去入口 → 重新接线回章节页
- 自定义 `404.html`：GitHub Pages 会把缺失路径留在地址栏，页面里所有相对地址都会解析错位
  （上线实测过 —— favicon、CSS、JS 全 404，页面裸奔）。改为在 `<head>` 最前面探测站点根
  并写成 `<base>`，域根 / 子路径 / 本地预览三种情况都成立

### 4. 门户页：让首页自己会说话

这是一门讲可视化的课，首页却最容易退化成「一段文字 + 一串链接」。所以每张章节卡片顶部配了一枚
**主题微缩图**：第 1 章是带类型表头的数据表，第 2 章是四段节点链，第 3 章是色相带 + 明度带，
第 4 章是散点，第 5 章是折线 + 面积。

纯内联 SVG、构建期写死 —— 不发额外请求、不依赖 JS，禁用脚本时图形依然在；
取色走 `--viz-*` 令牌，**切主题时图形自动跟着换**；整体 `aria-hidden`，不干扰读屏。

**知识图谱**把 26 个知识点和 5 个章节组织成一张可展开的网络：默认展开第 1 章，读者
一进来就能看到「知识点长什么样」，而不是又一张章节目录。点章节展开它的知识点、点知识点
在右侧看一句话总结与对应小节，跨章依赖边把五章连成一张网。力导向只负责「摆得开」——
没展开时五章吸附在固定半径的环上，每次打开图长得一样。d3 用动态 `import()`，且等图谱
滚进视口才加载，门户首屏不为第二屏的图付 280 KB。

节点可以拖动、画布可以平移缩放；缩小到读不清字时概念标签自动让位、只留章节名，
选中哪一章就把它的成员标签放回来。章节页顶部的「概念依赖图」是另一套渲染
（`conceptmap.js`，分层有向图，容器窄于 620px 换竖排树）。

### 5. 保底体验：脚本没跑、图看不清、页被分享

- **禁用 JS 也能读完正文**：三个 tab 的面板在脚本未接管时全部展开、tab 条隐藏。
  实测单章可见正文从 1208 字恢复到 3782 字。`data-tabs` 只在 tab 真正绑好后才会写到
  `<html>`，所以「脚本加载了但中途出错」也走兜底。
- **图片点开看大图**：原生 `<dialog>` + `showModal()`，ESC 关闭、焦点陷阱、`::backdrop`
  都由浏览器提供，不引第三方灯箱。视口外的懒加载图不会被误判成图标。
- **首页「关于这门课」**：理论来源（Card / Mackinlay / van Wijk / Munzner）、设计原则、
  技术栈、数据集出处，中英双语。
- **导览胶囊会让开正文**：固定在底部的「自动导览」在向下阅读时收起，向上滚再出现
  （导览进行中不收起）。手机上一行正文被它长期压住的问题由此解决。
- **分享与索引**：12 个页面补齐 `canonical` / `og:*` / `twitter:card`，并生成 1200×630
  `assets/og-cover.png`（用真实渲染截图，不是拼的）。

```
│   ├── lecture.html            讲义页（可打印）
│   └── data/                   该章演示数据
├── lesson-01/demo/             5 个可独立运行的实验（自包含，可单独拷走）
├── supplementary/              16 个页面（索引页 + 15 个独立 Demo）
├── assets/
│   ├── css/                    tokens / base / shell / content / portal
│   ├── js/                     shell / enhance / conceptmap / lesson / portal
│   │                           + demos/ch0X.js（按需动态 import）
│   ├── search-index.json
│   └── og-cover.png            分享封面 1200×630（由真实渲染截图生成）
└── tools/                      ※ 不参与部署，但请保留
    ├── build.py                内容管道：从原站快照抽取内容 + 统一外壳装配
    ├── build_supp.py           补充 Demo 修复与统一

    └── origin/                 原站快照（管道的输入，勿删）
```

## 开发与验证

```bash
python tools/build.py          # 重建全站（可重复执行，结果确定）
python tools/audit.py          # 静态审计：断链 / 绝对路径 / 残留 / a11y / 内容完整性 / 文档结构
node  tools/verify_render.mjs  # 本地浏览器跑 35 个页面 + 25 项交互与布局断言
node  tools/verify_render.mjs --shots   # 同时输出截图到 tools/screenshots/
node  tools/verify_live.mjs    # 部署后验证线上 404 页（子路径下样式是否正常）
python tools/package.py        # 打交付压缩包到 deliverables/
```

> `verify_render.mjs` 与 `verify_live.mjs` 都依赖 `puppeteer-core` 和本机的 Chrome / Edge。
> 前者默认连 `http://127.0.0.1:8099`，后者默认连线上地址，可用环境变量覆盖：
> `BASE=http://127.0.0.1:9000 node tools/verify_render.mjs`、`PROXY=http://127.0.0.1:7890 node tools/verify_live.mjs`。

`puppeteer-core` 通过 `NODE_PATH` 指向工作区的 `node_modules` 即可，
不需要在项目里装依赖：

```bash
NODE_PATH=C:/Users/<you>/.workbuddy/binaries/node/workspace/node_modules \
  node tools/verify_render.mjs
```

**当前状态：静态审计 0 问题；35/35 页面在真实浏览器中零报错、零失败请求；
交互与布局断言 25/25 通过；6 类页面 × 3 档窄屏共 18 个组合零横向溢出（含知识图谱容器内不横滚）。**

## 技术栈

纯 HTML + CSS + ES Modules。**零构建、零依赖、零外部请求。**
D3.js v7 内置在 `assets/js/vendor/`（ESM 与 UMD 各一份），断网也能把 27 个演示跑完；
`python -m http.server` 即可运行。

设计系统有 128 个 CSS 变量，分三层：原始色阶 → 语义令牌 → 组件。
换主题只动语义层。
