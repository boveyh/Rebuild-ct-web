Glossary

术语表

按章节顺序排列。每个词条除了「是什么」，还写了「为什么重要」—— 名词表最容易变成一份背了也没用的清单，加上后半句才有意义。

  • DIKW 金字塔DIKW pyramid

    第 1 章 数据

    把「数据 → 信息 → 知识 → 智慧」四级串起来的层次模型。数据是原始观察，信息是组织过的数据，知识是从信息里提炼出的规律，智慧是据知识做判断。 A four-level model: data → information → knowledge → wisdom.

    可视化的能力边界就在这里：它主要把数据升到信息，少数场景能到知识，跨不到智慧。分不清这一层，就很容易承诺可视化做不到的事。 It marks the boundary of visualization, which mostly lifts data to information.

  • 名义尺度Nominal scale

    第 1 章 数据

    Stevens 四种测量尺度里最弱的一种：只允许判断相等或不等，没有任何顺序。姓名、性别都属于这一类。 The weakest of Stevens' four scales: only equality can be tested.

    名义数据只能用色相、形状这类定性通道编码 —— 给性别做平均值是没有意义的。 Nominal data belongs on qualitative channels such as hue and shape.

  • 序数尺度Ordinal scale

    第 1 章 数据

    值之间有顺序，但相邻两级的差不一定相等。学历（本科 / 硕士 / 博士）是典型例子。 Values are ordered but the gaps between them need not be equal.

    差不一定相等，所以序数数据很适合用亮度、饱和度这类顺序通道，而不适合用位置。 Ordered channels such as brightness suit ordinal data better than position.

  • 区间尺度与比率尺度Interval vs. ratio scale

    第 1 章 数据

    区间尺度支持加减（摄氏温度），比率尺度还支持乘除（年龄、价格）。唯一的区别是有没有「真零点」。 Interval supports addition; ratio additionally supports multiplication. The difference is the true zero.

    0°C 不等于没有温度，所以不能说 20°C 是 10°C 的两倍；0 元才等于没有钱。这条决定了什么时候可以算比值。 0°C is not 'no temperature', so ratios of Celsius values are meaningless.

  • 视觉通道Visual channel

    第 1 章 数据

    承载数据变化的视觉属性，位置、长度、角度、面积、亮度、饱和度、色相、形状、纹理等。 A visual property that can carry data variation: position, length, angle, area, brightness, hue, shape.

    Mackinlay 把通道按表达能力排了序：位置最能表达定量，色相最能表达定性。属性与通道配错，信息就会丢。 Channels differ in how much information they carry; mismatch loses information.

  • Data-Join 三态Data-join, three states

    第 1 章 数据

    把数据数组绑定到 DOM 元素时出现的三种情况：元素不够是 enter，正好是 update，多了是 exit。 When binding data to elements: extra data enters, matching data updates, surplus elements exit.

    这是 D3 的核心心智模型。理解了它，D3 就从「一堆 API」变成「一条数据到画面的映射」。 It is the core mental model that turns D3 from an API list into a mapping.

  • key 函数Key function

    第 1 章 数据

    在绑定数据时告诉 D3「哪个数据对应哪个元素」的函数，通常写成 d => d.id。 A function that tells D3 which data item belongs to which element.

    没有 key，D3 按数组下标认身份：数据一重排，所有元素都算「变过」，过渡动画就乱了。有 key，元素才知道自己是谁。 Without it D3 matches by index, so any reordering breaks transition animations.

  • Card 数据流模型Card's pipeline model

    第 2 章 数据可视化流程

    把可视化拆成四步：原数据 → 数据表 → 视觉结构 → 视图。1999 年由 Stuart Card 提出。 Card's four-stage model: raw data → data tables → visual structures → views.

    它是整门课的骨架。有了这套坐标系，遇到任何一张陌生的图，你都能问「它在哪一步做了什么处理」。 It gives you a frame for asking what any unfamiliar chart does at each stage.

  • d3.rollupd3.rollup

    第 2 章 数据可视化流程

    按给定键分组，并对每组算出一个聚合值，返回 Map。和 d3.group 的区别是它只留聚合结果。 Groups by key and reduces each group to a single value.

    把平表变成层次结构最实用的一步。树形图、分组柱状图的上游数据几乎都是它生成的。 It is the usual first step from a flat table to hierarchical data.

  • Reingold-Tilford 布局Reingold–Tilford layout

    第 2 章 数据可视化流程

    一种经典树状图布局算法，让同层节点均匀铺开，同时父节点尽量居中于其子节点之上。 A classic tree layout that spreads siblings evenly and centres parents over children.

    手写树布局很容易左右不平衡、线条交叉。这个算法把「看起来舒服」这件事变成了可计算的规则。 It turns 'looks tidy' into a computable rule, avoiding crossings and imbalance.

  • 事件委托Event delegation

    第 2 章 数据可视化流程

    把监听器绑在父元素上，靠事件冒泡统一处理所有子元素的事件。 Attaching one listener to a parent and letting events bubble up from children.

    元素数量成千上万时，给每个元素单独绑监听器的开销会线性上涨。委托只有一个监听器，而且动态增删的子元素也能自动接管。 One listener scales where per-element listeners grow linearly.

  • 颜色空间Color space

    第 3 章 色彩专题

    描述颜色的坐标系。RGB 面向屏幕，HSL 面向直觉，Lab / HCL 面向感知。 A coordinate system for colour: RGB for screens, HSL for intuition, Lab/HCL for perception.

    做数据映射必须用感知均匀的空间：在 RGB 里等距离的两个颜色，人眼看着并不等距，映射出来的图会骗人。 Only perceptually uniform spaces give honest distances when mapping data to colour.

  • colormap 三类Three colormap types

    第 3 章 色彩专题

    顺序型（数值单调变化）、发散型（有一个有意义的中间值）、定性型（类别之间无顺序）。 Sequential, diverging and qualitative colormaps.

    选错类型的代价很大：给没有中心的数据用发散型，读者会读出一个不存在的中心；给类别数据用顺序型，读者会以为类别能比大小。 A wrong type misleads: diverging on data without a midpoint invents a centre.

  • 色觉缺陷（CVD）Colour-vision deficiency

    第 3 章 色彩专题

    红绿色盲、蓝黄色盲等色觉差异。男性中红绿色盲比例约为 8%。 Colour-vision deficiencies such as deuteranopia and protanopia.

    只靠色相区分数据，意味着约每十二个男性读者里就有一个读不了你的图。这是把「可读性」变成硬指标的少数几处之一。 Hue-only encoding excludes roughly one in twelve male readers.

  • Wong 色板Wong palette

    第 3 章 色彩专题

    发表在 Nature Methods (2011) 的一组定性色板，经过色觉缺陷友好性与等亮度检验。 A qualitative palette published in Nature Methods (2011), tested for CVD safety.

    本网站自身的配色也取自这套色板 —— 课程讲的配色原则，在课程网站自己身上先用一遍。 This very website uses it, so the course practices what it teaches.

  • 鲜艳 + 低饱和Vivid but low saturation

    第 3 章 色彩专题

    一类配色策略：保色相上的区分度（鲜艳），同时压低饱和度（不刺眼），并把颜色数量控制在 7 个以内。 A strategy that keeps hue separation while lowering saturation, capped around seven colours.

    高饱和多色最大的问题不是丑，是「吵」—— 每一块颜色都在抢注意力，读者反而找不到重点。 Highly saturated multi-colour palettes are not ugly so much as noisy — everything competes.

  • 三层坐标变换Three-layer coordinate transform

    第 4 章 低维数据可视化

    数据空间（语义）→ 坐标系空间（几何）→ 屏幕空间（像素）。每一层只负责一件事。 Data space (meaning) → coordinate space (geometry) → screen space (pixels).

    初学者常把这三种变换揉在一起写，于是改一处就崩一片。分层之后，比例尺该做什么、什么不该做，就清楚了。 Keeping the three layers separate stops a change in one from breaking the others.

  • Cleveland 45° 黄金角Cleveland's 45° sweet spot

    第 4 章 低维数据可视化

    人眼对斜率的估计在 45° 附近最准确（也称 banking to 45°）。 Human slope estimation is most accurate around 45°.

    它把「图表该多宽多高」从审美问题变成了感知问题：想让人准确比较趋势，就把主要趋势线摆到 45° 附近。 It turns aspect ratio from a matter of taste into a matter of perception.

  • Marching SquaresMarching Squares

    第 4 章 低维数据可视化

    在规则网格上逐格判断四角与阈值的关系，生成等值线段，再拼接成完整等值线的算法。 A grid algorithm that tests each cell's four corners against a threshold and stitches contour segments.

    它是等值线图和热力图平滑化的底层。难点不在循环，而在「四角两两高于阈值」时的歧义格子 —— 连线方式不同，结果形状会不一样。 Ambiguous cells (two high, two low corners) are the hard part, not the loop itself.

  • 时间的 5 个属性Five attributes of time

    第 5 章 时序数据可视化

    有序、连续、周期、独立于空间、有结构（间隔有含义）。 Ordered, continuous, cyclic, independent of space, and structured.

    其中「独立于空间」这一条最关键：空间数据的位置自带信息，时间必须由你决定它怎么落到平面上，所以时间可视化才有这么多非标准布局。 'Independent of space' is why time needs so many non-standard layouts.

  • van Wijk 日历热图van Wijk calendar heatmap

    第 5 章 时序数据可视化

    把一年按「行 = 年 / 列 = 周」摆成网格，用颜色表示每天的值。 A calendar grid with years as rows and weeks as columns, coloured by daily value.

    它牺牲了精确的数值比较，换来整年的模式识别 —— 这是布局设计里典型的「用精度换结构」。 A classic trade: precision for pattern recognition.

  • 阿基米德螺旋Archimedean spiral

    第 5 章 时序数据可视化

    半径随角度线性增长的螺旋线。把时间沿它排列，同一周期的数据会落在同一条辐射方向上。 A spiral whose radius grows linearly with angle.

    折线图会把周期切成碎片，螺旋则让周期对齐成径向的一条条 —— 周期性因此变得可以直接看出来。 Periodic events align along rays, making cyclicity directly visible.

  • StorylineStoryline

    第 5 章 时序数据可视化

    多角色叙事可视化：每条线代表一个角色、组织或进程，线的交叉表示它们相遇或产生关系。 A narrative visualization where each line is a character and crossings are encounters.

    它是少数几个能把「叙事结构」本身画出来的方法。《侏罗纪公园》案例里，角色线的交织就是剧情的结构。 It visualizes narrative structure itself, not just values.

  • 比例尺（scale）Scale

    第 1 章 数据

    把数据域映射到值域的函数。连续量用 scaleLinear，离散分类用 scaleBand，序数可用 scalePoint。 A function mapping a data domain to a visual range.

    选错比例尺是最常见的新手错误：给类别数据用线性比例尺，会算出「0.5 班」这种没有意义的值。 Using a linear scale on categorical data produces meaningless midpoints.

  • colormap 与色板的区别Colormap vs. palette

    第 3 章 色彩专题

    colormap 是连续的（可插值），用于数值映射；色板是离散的一组颜色，用于类别区分。 A colormap is continuous and interpolated; a palette is a discrete set for categories.

    把连续的 colormap 用在类别数据上，会暗示类别之间有中间态；把离散色板用在数值上，则会让读者以为数据是分档的。 Using one where the other belongs implies structure the data does not have.
