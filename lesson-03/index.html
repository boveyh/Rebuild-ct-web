3.1

颜色模型基础颜色模型基础

为什么要学颜色模型？

Why learn color models?

设计 colormap 时，不能直接用 RGB 插值——因为 RGB 不是感知均匀的（255,0,0 与 0,255,0 "看上去"亮度差很多）。你需要感知均匀的颜色空间（Lab / HCL）来插值，才能得到平滑的渐变。

When designing a colormap, do not interpolate directly in RGB—because RGB is not perceptually uniform (255,0,0 and 0,255,0 "look" very different in lightness). You need a perceptually uniform color space (Lab / HCL) to interpolate and get smooth gradients.

4 大颜色空间

The 4 major color spaces

  • RGB：加色模型，设备相关。屏幕显示的默认。
  • RGB: additive model, device-dependent. The default for screen display.
  • HSL：艺术家友好（色相/饱和度/亮度独立），但仍不感知均匀。
  • HSL: artist-friendly (independent hue / saturation / lightness), but still not perceptually uniform.
  • CIE Lab：感知均匀，设计 colormap 的黄金标准。
  • CIE Lab: perceptually uniform, the gold standard for designing colormaps.
  • CMYK：减色（印刷），web 可视化用不到。
  • CMYK: subtractive (print). Not used in web visualizations.

CVD（色觉缺陷）

CVD (Color Vision Deficiency)

约 8% 男性、0.5% 女性是色盲。常见三种：

About 8% of men and 0.5% of women are color-blind. Three common types:

  • 红色盲（protanopia）：约 1% 男性
  • Protanopia (red-blind): ~1% of men
  • 绿色盲（deuteranopia）：约 6% 男性（最常见）
  • Deuteranopia (green-blind): ~6% of men (most common)
  • 蓝色盲（tritanopia）：极罕见
  • Tritanopia (blue-blind): extremely rare

⭐ 关键点 1：RGB → HSL 手写

⭐ Key point 1: Hand-written RGB ↔ HSL

function rgbToHsl(r, g, b) {
            r /= 255; g /= 255; b /= 255;
            const max = Math.max(r, g, b), min = Math.min(r, g, b);
            let h, s, l = (max + min) / 2;
            if (max === min) { h = s = 0; }
            else {
              const d = max - min;
              s = l > 0.5 ? d / (2 - max - min) : d / (max + min);
              switch (max) {
                case r: h = (g - b) / d + (g < b ? 6 : 0); break;
                case g: h = (b - r) / d + 2; break;
                case b: h = (r - g) / d + 4; break;
              }
              h /= 6;
            }
            return [h * 360, s * 100, l * 100];
          }

⭐ 自己写 RGB↔HSL 是为了理解每一步的物理含义——"最大通道决定色相、相减决定饱和度"——比用 d3 库更能理解色相为什么在 0-360° 循环。

⭐ Writing RGB↔HSL yourself is to understand the physical meaning of each step—"the largest channel determines hue, the difference determines saturation"—which is more illuminating than using a d3 library for understanding why hue cycles between 0–360°.

⭐ Key point 2: CVD simulation matrix

const CVD_MATRICES = {
            deuteranopia: [
              [0.625, 0.375, 0.000],
              [0.700, 0.300, 0.000],
              [0.000, 0.300, 0.700]
            ],
            protanopia:   [[0.567, 0.433, 0.000], [0.558, 0.442, 0.000], [0.000, 0.242, 0.758]],
            tritanopia:   [[0.950, 0.050, 0.000], [0.000, 0.433, 0.567], [0.000, 0.475, 0.525]]
          };

          function simulateCVD([r, g, b], type) {
            const m = CVD_MATRICES[type];
            return [
              r * m[0][0] + g * m[0][1] + b * m[0][2],
              r * m[1][0] + g * m[1][1] + b * m[1][2],
              r * m[2][0] + g * m[2][1] + b * m[2][2]
            ].map(v => Math.round(Math.max(0, Math.min(255, v))));
          }

colormap 三类选择colormap 三类选择

三类 colormap 对应不同数据语义

Three colormap families match three data semantics

  • 顺序型（Sequential）：数据有自然顺序（人口、温度）。单调亮度 + 单调色相。例子：Viridis / Plasma / Cividis
  • Sequential: data with a natural order (population, temperature). Monotonic lightness + monotonic hue. Examples: Viridis / Plasma / Cividis
  • 发散型（Diverging）：数据有意义的"中点"（如 0、正负偏差、白人中位数）。两端异色，中间白/浅。例子：RdBu / BrBG / PiYG
  • Diverging: data with a meaningful "midpoint" (e.g., zero, signed deviation, white median). Different hues at the two ends, white/light in the middle. Examples: RdBu / BrBG / PiYG
  • 定性型（Qualitative）：数据无序（如产品类别）。色相区分、亮度接近。例子：Tableau10 / Set1 / Set3
  • Qualitative: unordered data (e.g., product categories). Distinct hues, similar lightness. Examples: Tableau10 / Set1 / Set3

典型错误

Common mistakes

用发散型 RdBu 画"50 州谋杀率"（有序数据）——中段接近白色，看上去"谋杀率 = 100 附近"的州是"中点"——但 100 没有任何语义，纯属误导。

Using the diverging palette RdBu for "murder rates in 50 states" (ordinal data)—the middle band looks near-white, so states with a murder rate "around 100" appear to be the "midpoint"—but 100 has no semantic meaning, so this is purely misleading.

CVD 友好检查清单

CVD-friendly checklist

  • Viridis / Cividis：✅ 优（Nature Methods 推荐）
  • Viridis / Cividis: ✅ excellent (recommended by Nature Methods)
  • RdBu / BrBG：△ 中等（红绿对色盲不友好）
  • RdBu / BrBG: △ moderate (red-green pairs are not CVD-friendly)
  • Tableau10（定性）：△ 与色相相关
  • Tableau10 (qualitative): △ hue-related issues
  • Jet（彩虹谱）：⚠ 禁用
  • Jet (rainbow): ⚠ do not use

3.3

CIE Lab 色域图CIE Lab 色域图

为什么需要 Lab 色域图？

Why do we need a Lab gamut diagram?

RGB 空间是立方体，但你不知道"哪些颜色真的存在、哪些会失真"。CIE Lab 是感知均匀空间，距离 ≈ 人眼感知差，是设计 colormap 和检查色域的标准。

RGB space is a cube, but you cannot tell "which colors actually exist and which would be distorted". CIE Lab is a perceptually uniform space, distance ≈ perceived difference, and is the standard for designing colormaps and checking gamut.

三个色域（嵌套关系）

Three gamuts (nested relationship)

  • sRGB：屏幕通用标准（Web/PPT/一般科研图）
  • sRGB: universal screen standard (Web / PPT / general scientific figures)
  • Adobe RGB：摄影/印刷，绿域更广
  • Adobe RGB: photography / print, wider green gamut
  • Rec.2020：4K 电视/HDR，色域最大
  • Rec.2020: 4K TV / HDR, the largest gamut

超出 sRGB 的颜色（如高饱和度的纯绿）在普通屏幕上显示不出来，会被 clamp。

Colors outside sRGB (e.g., highly saturated pure green) cannot be displayed on ordinary screens and get clamped.

实战用法

Practical usage

  • 从 d3.lab(L, a, b).rgb() 转换时，超出 sRGB 的颜色会自动 clamp
  • When converting from d3.lab(L, a, b).rgb(), colors outside sRGB are clamped automatically
  • 设计 colormap 时用 d3.interpolateLab（在 Lab 空间插值），比 d3.interpolateRgb 平滑得多
  • When designing colormaps, use d3.interpolateLab (interpolates in Lab space), which is far smoother than d3.interpolateRgb
  • 高饱和度色仅在打印/4K 屏幕上"存在"，Web 上看不一定准确
  • Highly saturated colors only "exist" on print / 4K screens, and may not look accurate on the Web

色系搭配规则（5 大类）色系搭配规则（5 大类）

5 大色系规则

The 5 major color scheme rules

  • 单色 Monochromatic：同一色相不同亮度/饱和。安全、低风险。
  • Monochromatic: the same hue with varying lightness / saturation. Safe and low risk.
  • 类比 Analogous：色轮相邻 ±30°。和谐但缺少对比度。
  • Analogous: adjacent on the color wheel, within ±30°. Harmonious but lacking contrast.
  • 互补 Complementary：色轮正对面 180°。对比度强但易刺眼。
  • Complementary: directly opposite on the color wheel at 180°. Strong contrast but can be jarring.
  • 三等分 Triadic：色轮 120° 等分。3 种类别时最常用。
  • Triadic: evenly spaced at 120° on the color wheel. The most common choice for 3 categories.
  • 分裂互补 Split：互补色相邻 150°。温和版互补。
  • Split-Complementary: adjacent to the complement at 150°. A softer version of complementary.

选择原则

Selection principles

  • 严肃科研：单色（Nature 黑白经济型配色）
  • Serious scientific work: monochromatic (Nature-style black-and-white economical palette)
  • 层级 / 分组：类比
  • Hierarchy / grouping: analogous
  • 突出重点：互补（实验组 vs 对照组）
  • Highlight a focal point: complementary (treatment vs control)
  • 3 种类别：三等分
  • 3 categories: triadic
  • 一般情况：分裂互补（不刺眼又有对比）
  • General cases: split-complementary (not jarring, but still has contrast)

4 个典型错误

4 typical mistakes

  • ⚠ 彩虹谱 Jet：非感知均匀 + CVD 不友好 + 打印不友好。Nature 已禁用。
  • ⚠ Rainbow palette Jet: not perceptually uniform + not CVD-friendly + not print-friendly. Nature has banned it.
  • ⚠ 红绿对比：红绿色盲眼中几乎变成同色（最严重的可访问性问题）
  • ⚠ Red-green contrast: to a red-green colorblind viewer, they almost become the same color (the most serious accessibility issue)
  • ⚠ 颜色过多 12 色：超过 7 种时眼睛无法区分
  • ⚠ Too many colors (12): the eye cannot distinguish beyond 7
  • ✅ Wong 8 色：CVD 友好 + 灰度打印友好 + 类别数 ≤ 8
  • ✅ Wong 8-color: CVD-friendly + grayscale-print-friendly + ≤ 8 categories

教学要点

Teaching takeaways

让学生亲手投票，能加深对"为什么是错的"的理解——光看理论不如下场选错一次来得深。

Letting students vote by hand deepens their understanding of "why it is wrong"—just reading theory is not as powerful as making the wrong choice in person.

鲜艳 + 低饱和 哲学生成器鲜艳 + 低饱和 哲学生成器

你的配色哲学（落地到 3 条规则）

Your color philosophy (distilled into 3 rules)

  1. 颜色数量 ≤ 7：超过 7 种眼睛就分不清
  2. Color count ≤ 7: beyond 7 the eye cannot tell them apart
  3. 鲜艳颜色（高 H 区分度）：用 H 拉开类间距离（≥30°）
  4. Vivid colors (high H differentiation): use H to separate categories (≥ 30°)
  5. 低饱和度（S 30-50%）：每个色都别太"冲"，耐看
  6. Low saturation (S 30–50%): each color should not be too aggressive—easy on the eyes

经验公式

Empirical formulas

  • 主色 S = 70-80%（鲜明但不刺眼）
  • Primary color S = 70–80% (vivid but not harsh)
  • 配套色 S = 30-50%（低饱和，耐看）
  • Supporting color S = 30–50% (low saturation, easy on the eyes)
  • 强调色用互补或类比，不要全饱和
  • For accent colors, use complementary or analogous, avoid full saturation
  • 高亮用 L=85-90%（如背景、注释）
  • Highlights use L = 85–90% (e.g., for backgrounds, notes)

7 色生成规则

The 7-color generation rule

主色 + 2 类比（±30°）+ 1 类比低饱和 + 1 互补 + 1 互补低饱和 + 1 高亮 = 7 色，符合"≤ 7"原则。

Primary + 2 analogous (±30°) + 1 analogous low-saturation + 1 complementary + 1 complementary low-saturation + 1 highlight = 7 colors, conforming to the "≤ 7" principle.

function cvdTransformSvg(svgString, type) {
            const doc = new DOMParser().parseFromString(svgString, 'image/svg+xml');
            doc.querySelectorAll('[fill]').forEach(el => {
              const c = d3.color(el.getAttribute('fill'));
              if (!c) return;
              const rgb = [Math.round(c.rgb().r), Math.round(c.rgb().g), Math.round(c.rgb().b)];
              const sim = simulateCVD(rgb, type);
              el.setAttribute('fill', `rgb(${sim.join(',')})`);
            });
            return new XMLSerializer().serializeToString(doc);
          }
